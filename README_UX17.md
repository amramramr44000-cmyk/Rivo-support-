# Rivo Support Portal — UX17

## Admin ticket queue upgrade

- Active tickets are separated from closed tickets.
- Closed tickets appear only under the dedicated **مغلقة / Closed Archive** filter and are visually red.
- Tickets assigned to the current admin are blue and explicitly marked **مسؤوليتك**.
- Unassigned active tickets are green and marked **غير مستلم**.
- Tickets assigned to another admin are intentionally dimmed so ownership is obvious without hiding the ticket.
- Admins can still open any ticket and use the elevated UX16 actions without assignment restrictions.
- The same ticket records remain intact; this is a visual/workflow separation only.
